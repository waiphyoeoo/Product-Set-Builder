Bundle Purchase

This module allow to add bundle to a purchase order.
The code is well documented in case you want to adapt it to your need.

This module is available in English and French.


Bundle Purchase

Bundle Configuration

Configure your Bundles. A bundle must be a consumable product.

Add the bundle's components

You can add note and / or section.

Add the bundle to a purchase order

Use the "Add bundle" button.

Select your bundle

Select the quantity of bundle you want to add. The quantity of the components adapt automatically.
